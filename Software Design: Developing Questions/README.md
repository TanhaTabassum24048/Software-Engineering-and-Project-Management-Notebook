1. Course Outcomes (COs)
After completing the relevant Software Design topics, students should be able to:
CO	Course Outcome	Main content coverage
CO1	Define fundamental software design concepts and explain the purpose and outputs of the software design process.	Software design, architectural design, detailed design, design artifacts
CO2	Explain the principles of good software design, including modularity, low coupling, high cohesion, abstraction, encapsulation, and information hiding.	Design fundamentals and design quality
CO3	Describe software architecture and distinguish among common architectural styles.	Software architecture, layered, event-based, MVC, repository/blackboard, pipes-and-filters
CO4	Identify and explain the purpose and classification of object-oriented design patterns.	GoF patterns, creational, structural, behavioral, Strategy, Factory, Observer
CO5	Explain basic software design quality assessment metrics and fundamental user-interface design principles.	Design reviews, CK metrics, CBO, LCOM, WMC, UI principles and modalities
