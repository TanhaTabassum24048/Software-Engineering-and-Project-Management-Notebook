# Daily Drink Water Reminder System

## Project Overview
The Daily Drink Water Reminder System is a simple software application designed to help users maintain regular water-drinking habits. It allows users to set a daily water-intake goal, record water consumption, monitor daily progress, and configure reminder preferences.

## Objectives
- Set and update daily water-intake goals.
- Record consumed water in millilitres.
- Track daily progress toward the water-intake goal.
- Configure water-drinking reminders.
- View daily water-intake history.

## Technologies Used
- **Programming Language:** Java
- **User Interface:** Java Swing
- **Database:** SQLite (planned)
- **Software Process Model:** Iterative and Incremental Model

## Main Features
- Daily hydration dashboard
- Water-intake tracking
- Goal progress calculation
- Reminder settings
- Intake history
